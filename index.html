01

Battlesnake

A snake that plans every move in half a second.

Battlesnake is snake played by code. Each turn the game sends your server the board, and you have 500 milliseconds to pick a direction. Last snake alive wins.

Mine is written in Rust. It looks ahead and assumes the other snakes will team up on it, because most games are lost by walking into a dead end. A new idea has to pass an 800-game test before it ships. While I was playing, it held a top-3 spot on the leaderboard.

Rust · private repo

02

Screeps

An MMO you can only play by writing code.

In Screeps you never click a unit. Your JavaScript runs on a shared server every tick and keeps your colony going around the clock.

I've played on and off since 2024 and rebuilt my bot from scratch in October. It plays on shard 3, and I test it on a private server on my Mac mini that runs 40 times faster.

TypeScript · private repo

The screen is my room E14S33, recorded from the game client.
03

Screeps Arena

Screeps as short one-on-one matches.

Two players' code meets on a small map for a single match. In Spawn Strike you win by destroying the other spawn.

My bot builds an army, keeps a few units home, and pushes. I test it in my own offline simulator against copies of other players' strategies.

Crew

A team of agents, each in its own container.

Crew was the seventh runtime. Every agent got its own Docker container and worked with me over Discord and a desktop app, using Claude Code or Codex underneath.

I built it in 22 days: 314 commits and about 100,000 lines.

Squad

An open-source agent platform built around subagents.

Agents share a task list with you, start helper agents with their own models and budgets, and ask you multiple-choice questions that show up as buttons in Discord.

It was the main Lobs platform until June.

excalive

Slides and narrated videos from one markdown file.

Draw scenes in Excalidraw, write what to say at each step, and excalive turns it into a slide deck or a video read by a local voice. Before it renders, it checks that every word on screen gets said.
